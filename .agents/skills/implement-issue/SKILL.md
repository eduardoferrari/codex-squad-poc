# Implement GitHub Issue

Follow this workflow:

1. Read the GitHub issue provided in the task.
2. Inspect the existing implementation before changing anything.
3. Identify the smallest coherent implementation.
4. Implement the requested functionality.
5. Add or update automated tests.
6. Run the complete test suite.
7. Review the final diff.
8. Do not modify unrelated files.
9. Report what was changed and which tests were executed.
