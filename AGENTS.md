# Project Instructions

## Project

This is a small Python project used to test autonomous Codex workflows.

## Repository structure

- `src/` contains application code.
- `tests/` contains automated tests.
- `.agents/skills/` contains project-specific Codex skills.

## Development rules

- Keep changes small and focused.
- Follow the existing project structure.
- Do not introduce unnecessary dependencies.
- Every behavior change must have automated tests.
- Run the test suite after making changes.

## Definition of Done

A task is complete only when:

1. The requested functionality is implemented.
2. Automated tests are added or updated.
3. All tests pass.
4. The working tree contains only intentional changes.
